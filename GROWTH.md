# GROWTH.md — Notte Visibility & Community Playbook

> A practical guide to increase Notte's visibility as the go-to framework for building reliable, cost-efficient web automation agents.

## TL;DR

Notte's hybrid approach (script + AI) is a genuine differentiator — 2.4x faster than competitors, 96.6% reliability, 50%+ cost reduction. This playbook focuses on getting that message in front of the right developers.

---

## 1. Positioning & Messaging

### Core Positioning
**"The web agent framework built for production"** — not another demo, but battle-tested infrastructure for real automation.

### Key Differentiators (use these in all content)
| What | Why It Matters |
|------|----------------|
| Hybrid Workflows | Script deterministic parts, AI only when needed → 50%+ cost reduction |
| Benchmark Performance | 86.2% self-report accuracy, 47s/task, 96.6% reliability |
| vs Browser-Use | 2.4x faster, 13% higher reliability |
| Playwright Compatible | Familiar API, easy migration |
| Enterprise Features | Vault, Persona, CAPTCHA solving, proxies |

### One-liner Options
- "Build production web agents in minutes, not weeks"
- "Web agents that actually work at scale"
- "Playwright meets AI agents — hybrid workflows for 50% cost reduction"

## 4. Contributor Community Building

### Good First Issues
Label issues with `good-first-issue` for:
- Documentation improvements
- Example scripts for common use cases
- Error message clarity
- Type hints coverage

### Discord/Slack Community
If not already active:
- Create `#showcase` for users to share projects
- `#help` with regular maintainer presence
- `#contributors` for development discussion
