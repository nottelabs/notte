# GROWTH.md — Visibility Checklist for Notte

> A practical growth checklist for Notte. Focused on reaching web automation developers who need **reliability at scale** without burning LLM costs.

## Positioning (TL;DR)

Notte's edge is clear: **hybrid workflows**. While others run pure LLM agents (expensive, slow), Notte lets you script deterministic parts and use AI only when needed — 50%+ cost savings with better reliability.

The benchmark numbers speak for themselves:
- 86% success rate vs Browser-Use's 77%
- 47s per task vs 113s
- 96.6% task reliability vs 83%

This is the story worth telling: "Why pay 2x for slower, less reliable automation?"

## 2. Content That Converts

### Technical Comparisons (High Impact)

| Topic | Format | Why It Works |
|-------|--------|--------------|
| "Notte vs Browser-Use: Benchmark Deep Dive" | Blog + GH Discussion | Developers love data. You have it. |
| "Why hybrid workflows beat pure LLM agents" | Tutorial | Explains the core differentiator |
| "Cutting web automation costs 50% with Notte" | Video/Demo | CFOs care about this |
| "From Playwright to Notte: Migration Guide" | Docs | Captures existing Playwright users |

### Demo Ideas

1. **Side-by-side comparison** — Same task, Notte vs Browser-Use, show time & cost
2. **Real-world workflow** — Login → navigate → extract → export with hybrid approach
3. **CAPTCHA solving demo** — Live stealth features in action

## 3. Community Building

### Developer Relations

- **Discord/Slack:** You have GitHub Discussions — pin "Show your workflow" thread
- **Office hours:** Monthly live debugging/Q&A sessions
- **Integration guides:** Connect with popular tools (LangChain, LlamaIndex, n8n)

### Contributor Growth

- Label `good-first-issue` on setup/docs tasks
- Create `integrations/` directory for community contributions
- Shout out contributors in releases

## 5. What to Avoid

- ❌ Don't lead with "AI agent" — everyone says that
- ❌ Don't spam — quality posts only
- ❌ Don't ignore the benchmark advantage — it's your best asset
- ❌ Don't forget Playwright users — they're your warmest leads
