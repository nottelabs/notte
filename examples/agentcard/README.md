# Agentcard with Notte

`runCheckout` blocks service workers in the dedicated context of a newly created Notte session, then attaches the Agentcard SDK before your merchant automation runs, so the SDK can pause the card request. Your app supplies the checkout actions, a private approval-link delivery callback, and an authoritative merchant-order reader. It returns a status, optional confirmed order ID, and the Notte session ID.

Requires Node.js 24+, `NOTTE_API_KEY`, and [Agentcard sandbox credentials](https://app.agentcard.sh). Run `npm ci`. Create `Agentcard` from `@agent-cards/sdk` with your sandbox `AGENTCARD_CLIENT_ID`, `AGENTCARD_CLIENT_SECRET`, and `sandbox: true`; pass it with `AGENTCARD_USER_ID` to the exported helper in `src/main.ts`. First link a test card to that user using the [Vault quickstart](https://docs.agentcard.com/vault/quickstart).

Implement `purchase(page)` for your sandbox merchant. Deliver `onApprovalUrl` only through your application's private user channel. Implement `readMerchantOrder(page, state)` using the merchant's confirmation page or order API; approval alone does not confirm an order. After `purchase` returns, the helper waits for the paused payment to be approved, declined, or expired before it reads the merchant order. The wait lasts up to 16 minutes, since Agentcard expires approvals after 15. It always ends 2 minutes before the 30-minute Notte session does, leaving time to read the order and clean up. The helper does not log payment details or approval URLs, record browser traces, or retry a payment.

The helper attempts to close the page, browser connection, and owned session. After reconciliation, cleanup failures preserve the checkout result and add a sanitized `cleanup_errors` list: `checkout_cancel`, `page_close`, `browser_close`, or `session_stop`. If session cleanup fails, use the returned session ID to inspect and stop that owned session separately; do not repeat the purchase. No existing session or persistent profile is reused. For pending, unknown, or user-action outcomes, follow up through the merchant before starting another checkout. See [Agentcard's completion guide](https://docs.agentcard.com/vault/completing-a-purchase).

Run `npm test` for adapter contracts. Set `NOTTE_AGENTCARD_LIVE=1` and an explicit `NOTTE_API_URL`, then run `npm run test:live` for real SDK attachment and browser cleanup without vendor calls or payments. On November 12, 2026, a full sandbox purchase on `shop.agentcard.sh` passed: card request paused, passkey approval, payment, and merchant confirmation. Validate your own merchant in sandbox before production.

The published SDK is used as an unmodified dependency under its license. No proprietary SDK implementation or data is included here.
