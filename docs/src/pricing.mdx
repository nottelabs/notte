## Usage Costs

Usage is paid from dollar-based credits. Credits cover browser sessions, functions, proxies, and LLM tokens.

<CardGroup cols={2}>
  <Card title="Browser Usage" icon="tv">
    **$0.01 / hour**

    Charged per minute, rounded up.
  </Card>
  <Card title="Function Runtime" icon="code">
    **$0.05 / hour**

    Runtime of deployed Functions.
  </Card>
  <Card title="Proxy Usage" icon="globe">
    **$10 / GB**

    Premium residential proxies.
  </Card>
  <Card title="LLM Usage" icon="microchip-ai">
    **Token price + plan markup**

    No markup on Free. +50% on Developer, +40% on Startup when using Notte-managed keys.
  </Card>
</CardGroup>

Proxy bandwidth is also metered on sessions that use your own proxy, with a partial credit. See [proxy billing](/features/sessions/proxies#billing).

## Plans

<Tabs>
  <Tab title="Free">
    ### Free - $0

    Great for trying Notte and small personal projects.

    | Included | Value |
    |----------|-------|
    | Credits | $10, granted once, no expiry (1,000 browser hours) |
    | Concurrency | 5 browsers |
    | LLM markup | None |
  </Tab>
  <Tab title="Developer">
    ### Developer - $20/mo

    Affordable entry with monthly credits.

    | Included | Value |
    |----------|-------|
    | Credits | $20/mo (2,000 browser hours) |
    | Concurrency | 25 browsers |
    | LLM markup | +50% on Notte-managed keys |
  </Tab>
  <Tab title="Startup">
    ### Startup - $100/mo

    Scale your agents with higher limits and features.

    | Included | Value |
    |----------|-------|
    | Credits | $100/mo (10,000 browser hours) |
    | Concurrency | 100 browsers |
    | LLM markup | +40% on Notte-managed keys, 20% of token cost with your own keys |
    | BYO | Keys & Proxies |
  </Tab>
  <Tab title="Enterprise">
    ### Enterprise - Custom

    Custom limits, SSO, SLAs and dedicated support.

    | Included | Value |
    |----------|-------|
    | Credits | Usage-based |
    | Concurrency | 250+ browsers |
    | BYO | Keys, Proxies, Cloud |
    | Compliance | SSO, SLAs, HIPAA |
  </Tab>
</Tabs>

Monthly plan credits refresh each billing cycle and expire at the end of it. Free credits and purchased top-ups do not expire.

Advanced stealth, Notte's highest-fidelity browser environment, is available to approved workspaces on request.
