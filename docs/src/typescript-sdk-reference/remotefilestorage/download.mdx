Download a file to `<localDir>/<filename>` and return the local path. The
file is written atomically (temporary file + rename). Rejects with
`FileExistsError` when the destination exists unless `force` is set.

```typescript
RemoteFileStorage.download(fileId: string, localDir?: string, options?: FileDownloadOptions): Promise<string>;
```

## Parameters

<ParamField body="fileId" type={"string"} required>
ID of the file to download.
</ParamField>

<ParamField body="localDir" type={"string"}>
Destination directory, created if needed. Defaults to the current directory.

Default:

```typescript
'.'
```
</ParamField>

<ParamField body="options" type={"FileDownloadOptions"}>
Set `force` to overwrite an existing destination; defaults to false.

Default:

```typescript
{}
```
</ParamField>

## Returns

```typescript
Promise<string>
```

The local file path after the download has been written successfully.

## Raises

- NotteAPIError if the storage API request fails.
- InvalidRequestError if storage has not been bound to a session.
- FileExistsError if the destination exists and `force` is false. Filesystem errors also propagate.

## Example

```typescript
const path = await storage.download(fileId, './downloads', { force: true });
```
