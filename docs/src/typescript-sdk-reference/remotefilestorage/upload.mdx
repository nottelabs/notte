Upload a file to the session. A string is read as a local path and its
basename becomes the uploaded filename unless `uploadFileName` is set.

```typescript
RemoteFileStorage.upload(file: UploadableFile, uploadFileName?: string): Promise<SessionFile>;
```

## Parameters

<ParamField body="file" type={"UploadableFile"} required>
Local file path, Blob, File, or buffer to upload.
</ParamField>

<ParamField body="uploadFileName" type={"string"}>
Optional stored filename. Local paths default to their basename; File objects keep their name.
</ParamField>

## Returns

```typescript
Promise<SessionFile>
```

Metadata for the uploaded file, including its ID, name, and size.

## Raises

- NotteAPIError if the storage API request fails.
- InvalidRequestError if storage has not been bound to a session.
- InvalidRequestError if a supplied local path is not a file.

## Example

```typescript
await storage.upload('./data/resume.pdf');
await storage.upload(Buffer.from('hello'), 'hello.txt');
```
