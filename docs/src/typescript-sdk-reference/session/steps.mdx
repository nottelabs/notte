Get one page of the session's steps. Each step has the shape of an item of
`status().steps`. Pass the page's `next_cursor` back as `cursor`, as is, to
get the next page; it is `null` on the last page. Works after `stop()`.

```typescript
Session.steps(options?: SessionStepsOptions): Promise<SessionStepsResponse>;
```

## Parameters

<ParamField body="options" type={"SessionStepsOptions"}>
Default:

```typescript
{}
```
</ParamField>

## Returns

```typescript
Promise<SessionStepsResponse>
```

## Raises

- NotteAPIError with status 400 when `cursor` is no longer valid: restart from the first page (no `cursor`).

## Example

```typescript
let page = await session.steps({ limit: 50 });
while (page.next_cursor !== null) {
  page = await session.steps({ cursor: page.next_cursor, limit: 50 });
}
```
