Execute an action on the current page.

When the action fails and `raiseOnFailure` is true (the default, see the
session option), the structured `exception_detail` returned by the API is
rehydrated into an `ActionExecutionError` whose `errorType` names the
server-side error class. `captcha_solve` actions get a 100 s request
timeout and are retried up to 3 times on HTTP 408.

```typescript
Session.execute(action: ExecuteAction, options?: boolean | ExecuteOptions): Promise<ApiExecutionResponse>;
```

## Parameters

<ParamField body="action" type={"ExecuteAction"} required>
Action type, target, and action-specific arguments.
</ParamField>

<ParamField body="options" type={"boolean | ExecuteOptions"}>
Override failure handling for this call; otherwise use the session setting.

Default:

```typescript
{}
```
</ParamField>

## Returns

```typescript
Promise<ApiExecutionResponse>
```

The execution response, including `success` and failure details when throwing is disabled.

## Raises

- ActionExecutionError if the action fails and failure throwing is enabled.
- NotteAPIError if the API request fails.

## Example

```typescript
import { actions } from 'notte-sdk';

await session.execute({ type: 'goto', url: 'https://www.notte.cc' });
await session.execute(actions.fill({ selector: "input[name='email']", value: 'user@example.com' }));
const result = await session.execute({ type: 'click', id: 'B1' }, { raiseOnFailure: false });
if (!result.success) console.log(result.message);
```
