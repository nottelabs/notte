Context manager pattern: start the session, run the callback and stop the
session, with close reason `error` when the callback throws.

Always waits for Managed Auth readiness before invoking the callback.

```typescript
Session.use<T>(callback: (session: Session) => Promise<T>, options?: AuthWaitOptions): Promise<T>;
```

## Parameters

<ParamField body="callback" type={"(session: Session) => Promise<T>"} required>
Async work to perform with the ready session.
</ParamField>

<ParamField body="options" type={"AuthWaitOptions"}>
Controls the Managed Auth readiness wait, including timeout and cancellation.

Default:

```typescript
{}
```
</ParamField>

## Returns

```typescript
Promise<T>
```

The callback's return value after session cleanup has been attempted.

## Raises

- Error if startup fails, the callback throws, or cleanup fails after a successful callback.

## Example

```typescript
await client.Session().use(async session => {
  await session.execute({ type: 'goto', url: 'https://www.notte.cc' });
});
```
