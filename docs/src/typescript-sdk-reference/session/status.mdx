Get the current status of the session. Like Python, this keeps working
after `stop()` (for example to read the recorded `steps`).

```typescript
Session.status(): Promise<SessionResponse>;
```

## Returns

```typescript
Promise<SessionResponse>
```

Current session metadata, including lifecycle status and recorded steps. Works after `stop()`.

## Raises

- Error if this session has never been started.
- NotteAPIError if the status request fails.

## Example

```typescript
const status = await session.status();
console.log(status.status); // 'active'
```
