client. Every API failure rejects with a `NotteAPIError`.

## Usage

- [download](/typescript-sdk-reference/files/download): Download a file's bytes as a `Blob`.
- [upload](/typescript-sdk-reference/files/upload): Upload bytes as a session file. `filename` is what the browser sees when the file is later attached to a page.
- [list](/typescript-sdk-reference/files/list): List the session's non-expired files, newest first.
- [metadata](/typescript-sdk-reference/files/metadata): Find a file's metadata by ID by scanning the session listing. Rejects with `FileNotFoundError` when the ID is unknown or expired.
- [stream](/typescript-sdk-reference/files/stream): Stream a file's bytes. Used by `RemoteFileStorage.download()` to write to disk without buffering.
