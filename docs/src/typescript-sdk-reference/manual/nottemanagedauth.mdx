## Usage

- [checkConnection](/typescript-sdk-reference/nottemanagedauth/checkconnection): Run only the verifier; this does not submit login credentials.
- [getOperation](/typescript-sdk-reference/nottemanagedauth/getoperation)
- [waitForAuth](/typescript-sdk-reference/nottemanagedauth/waitforauth): Wait for an accepted operation. Aborting this wait does not cancel the server operation.
- [refreshConnection](/typescript-sdk-reference/nottemanagedauth/refreshconnection): Verify first, logging in only when required and automatic recovery is allowed.
- [reauthenticateConnection](/typescript-sdk-reference/nottemanagedauth/reauthenticateconnection): Explicitly request a new login. Conflicting operations remain HTTP 409 errors.
