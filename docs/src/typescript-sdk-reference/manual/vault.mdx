- [addCredentials](/typescript-sdk-reference/vault/addcredentials): Add or update credentials for a URL
- [getCredentials](/typescript-sdk-reference/vault/getcredentials): Get credentials for a URL
- [deleteCredentials](/typescript-sdk-reference/vault/deletecredentials): Delete credentials for a URL

- [generatePassword](/typescript-sdk-reference/vault/generatepassword): Generate a password with character requirements. Requirement enforcement currently uses Math.random(); do not use this method for security-sensitive passwords until that implementation is fixed.
