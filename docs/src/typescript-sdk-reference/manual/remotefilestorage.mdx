File storage bound to a session, the counterpart of Python's
`RemoteFileStorage`. Create it unbound and pass it to `client.Session({ storage })`
so the session binds it on start, or bind it yourself with a session ID.

```ts
const storage = new RemoteFileStorage(client, sessionId);
const uploaded = await storage.upload('./resume.pdf');
const localPath = await storage.download(uploaded.id, './downloads');
```

## Usage

- [setSessionId](/typescript-sdk-reference/remotefilestorage/setsessionid): Bind the storage to a session. Called by `Session.start()` when the storage was passed to the session.
- [forSession](/typescript-sdk-reference/remotefilestorage/forsession): Bind this storage once, cloning it when another session already owns it.
- [upload](/typescript-sdk-reference/remotefilestorage/upload): Upload a file to the session. A string is read as a local path and its basename becomes the uploaded filename unless `uploadFileName` is set.
- [list](/typescript-sdk-reference/remotefilestorage/list): List the session's files.
- [metadata](/typescript-sdk-reference/remotefilestorage/metadata): Metadata of a file by ID. Rejects with `FileNotFoundError` when unknown.
- [download](/typescript-sdk-reference/remotefilestorage/download): Download a file to `<localDir>/<filename>` and return the local path. The file is written atomically (temporary file + rename). Rejects with `FileExistsError` when the destination exists unless `force` is set.
- [downloadBlob](/typescript-sdk-reference/remotefilestorage/downloadblob): Download a file's bytes as a `Blob` without touching the local filesystem.
- [delete](/typescript-sdk-reference/remotefilestorage/delete): Delete a session file.
