Browser session created with `client.Session(options)`.
Call `start()` before using it and `stop()` when finished, or use `use()`
to start and stop automatically around an asynchronous callback.

## Usage

- [start](/typescript-sdk-reference/session/start): Start the session - creates a new session on the server
- [stop](/typescript-sdk-reference/session/stop): Stop the session - terminates the session on the server
- [observe](/typescript-sdk-reference/session/observe): Observe the current page state
- [execute](/typescript-sdk-reference/session/execute): Execute an action on the page
- [scrape](/typescript-sdk-reference/session/scrape): Scrape the current page
- [replay](/typescript-sdk-reference/session/replay): Get session replay data
- [setCookies](/typescript-sdk-reference/session/setcookies): Set cookies for the session
- [getCookies](/typescript-sdk-reference/session/getcookies): Get cookies from the session
- [viewer](/typescript-sdk-reference/session/viewer): Open the live viewer for this session in the local default browser.
- [status](/typescript-sdk-reference/session/status): Get session status
- [use](/typescript-sdk-reference/session/use): Context manager pattern - automatically start and stop session
- [setCookiesFromFile](/typescript-sdk-reference/session/setcookiesfromfile): Set cookies from a file
