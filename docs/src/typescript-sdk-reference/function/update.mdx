Upload a new version of the code, mirroring `function.update(path=...)`.

```typescript
NotteFunction.update(options: FunctionUpdateOptions): Promise<FunctionResponse>;
```

## Parameters

<ParamField body="options" type={"FunctionUpdateOptions"} required>
Local Python file path, optional version, and code-access settings.
</ParamField>

## Returns

```typescript
Promise<FunctionResponse>
```

Updated function metadata, including its latest version.

## Raises

- InvalidRequestError if the path is missing or does not end in `.py`.
- NotteAPIError if the upload is rejected.

## Example

```typescript
const updated = await fn.update({ path: './scraper.py' });
console.log(updated.latest_version);
```
