Get the download URL of the function code, decrypting it when the API
returns an encrypted one (Notte managed functions).

```typescript
NotteFunction.getUrl(options?: FunctionUrlOptions): Promise<string>;
```

<ParamField body="options" type={"FunctionUrlOptions"}>

```typescript
{}
```

## Returns

```typescript
Promise<string>
```

An HTTP(S) URL for downloading the function source.

## Raises

- InvalidRequestError if an encrypted URL has no usable decryption key.
- NotteError if decryption does not produce an HTTP(S) URL.
