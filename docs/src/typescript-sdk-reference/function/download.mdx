Download the function code as a python file. Returns the code, and writes
it to `path` when one is provided.

```typescript
NotteFunction.download(options?: FunctionDownloadOptions): Promise<string>;
```

## Parameters

<ParamField body="options" type={"FunctionDownloadOptions"}>
Optional version, decryption key, and local `.py` destination path.

Default:

```typescript
{}
```
</ParamField>

## Returns

```typescript
Promise<string>
```

The Python source text, including when a local destination is supplied.

## Raises

- InvalidRequestError if the destination does not end in `.py` or the decryption key is invalid.
- NotteError if the source download fails. Local filesystem failures also propagate.

## Example

```typescript
const code = await fn.download({ path: './scraper.py' });
```
