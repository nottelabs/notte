Delete the function permanently. This cannot be undone, so it must be confirmed.

A function with deletion protection on cannot be deleted until it is turned off
with `updateMetadata({ deletion_protected: false })`.

```typescript
NotteFunction.delete(options: FunctionDeleteOptions): Promise<DeleteFunctionResponse>;
```

## Parameters

<ParamField body="options" type={"FunctionDeleteOptions"} required>
Must set `confirm` to `true`.
</ParamField>

## Returns

```typescript
Promise<DeleteFunctionResponse>
```

The API's function-deletion confirmation.

## Raises

- InvalidRequestError if `confirm` is not `true`.
- NotteAPIError if the function cannot be deleted.

## Example

```typescript
await fn.delete({ confirm: true });
```
