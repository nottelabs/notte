Roll the function back to a previous version.

```typescript
NotteFunction.rollback(options: FunctionRollbackOptions): Promise<FunctionResponse>;
```

## Parameters

<ParamField body="options" type={"FunctionRollbackOptions"} required>
Target version and optional code-access restriction, which defaults to true.
</ParamField>

## Returns

```typescript
Promise<FunctionResponse>
```

Updated function metadata after rollback.

## Raises

- NotteAPIError if the requested version cannot be restored.

## Example

```typescript

await fn.rollback({ version: versions[0] });
```
