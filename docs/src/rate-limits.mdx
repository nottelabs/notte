## Request Limits

Session starts, agent starts, and the prompt helper endpoints are rate limited per API key, with a separate budget for each endpoint. Requests over the limit return `429`. See [API rate limits](/api-reference/rate-limits).

| | Free | Developer | Startup | Enterprise |
|--|------|-----------|---------|------------|
| **Per minute** | 50 | 50 | 100 | Custom |
| **Per hour** | 200 | 200 | 1,000 | Custom |
| **Per day** | 600 | 600 | 10,000 | Custom |
