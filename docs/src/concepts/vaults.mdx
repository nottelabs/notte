## Overview

Notte provides an enterprise-grade secure vault system that lets your sessions authenticate without your code ever handling the secrets.
All sensitive data is encrypted at rest and in transit, and credentials are never exposed to LLMs (including the coding agents that write your automations) or third-party services.
This ensures your passwords, API keys, and other secrets remain protected while your automations log in and interact with services on your behalf.

## Secure your credentials

Your credentials are protected with multiple layers of security:

- **End-to-End Encryption**: All secrets are encrypted at rest and in transit.
- **Zero Trust Architecture**: Credentials are never forwarded to LLM calls or external services.
- **Restricted Access**: Only sessions you attach the vault to can use your credentials.
- **2FA Support**: Comprehensive support for two-factor authentication credentials.

## How it works

![vault-fill-action](/images/vault-fill-action.png)

The Vault acts as an intermediary between your code and the browser session.
Attach a vault to a session with `client.Session(vault_id=...)`, then fill forms with placeholder values (`EMAIL`, `PASSWORD`, `MFA`, ... from `notte_core.credentials`).
When a `fill` or `form_fill` action contains a placeholder, the vault takes over the execution and replaces the dummy value with the actual
credential for the current website, directly inside the browser.

The significant security benefit of this approach is that neither your code nor the LLM that wrote it ever sees the actual credentials.

## Security Guarantees

- 🔒 Credentials are never stored in plain text
- 🔒 No credential data is sent to LLM providers
- 🔒 All credential operations are performed locally
- 🔒 Access to credentials is strictly controlled and logged
- 🔒 Open-source implementation for transparency
