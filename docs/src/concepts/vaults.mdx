## Overview

Notte provides an enterprise-grade secure vault system that allows you to safely share authentication details with AI agents.
Secrets are encrypted at rest and in transit. During supported credential-fill actions, the vault substitutes real credentials for placeholders outside the model context. The target website receives the credentials needed to authenticate. Treat browser access, screenshots, page content, and downloaded files as sensitive; placeholder substitution is not a guarantee that a website cannot reveal a submitted value.

## Secure your credentials

Your credentials are protected with multiple layers of security:

- **Encryption**: Secrets are encrypted at rest and in transit.
- **Credential substitution**: Supported fill actions resolve placeholders outside the model context.
- **Access control**: Authorized API clients and agents can use the vault.
- **2FA Support**: Comprehensive support for two-factor authentication credentials.

## How it works

![vault-fill-action](/images/vault-fill-action.png)

The Vault acts as an intermediary between the LLM agent and the browser session.
Some actions like `FillActions` may contain secure information such as passwords, credit card numbers, MFA secrets, etc.
When the system detects that the intent of the LLM Agent is to use such sensitive information, the vault takes over the execution and manually replaces the dummy
credentials provided by the LLM with the actual credentials based on the content of the vault.

This avoids including the real credential in the model-generated fill action.

## Handling credentials

Use vault placeholders instead of putting real passwords in prompts or source code. Credential substitution happens outside the model context, but the browser still interacts with the destination website. Avoid logging secrets and review what your automation captures or shares.
