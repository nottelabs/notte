## Overview

Notte provides a secure vault system that lets sessions authenticate using credential placeholders. Secrets are encrypted at rest and in transit. During supported credential-fill actions, the vault substitutes real credentials for placeholders outside the model context. The target website receives the credentials needed to authenticate. Treat browser access, screenshots, page content, and downloaded files as sensitive; placeholder substitution is not a guarantee that a website cannot reveal a submitted value.

## Secure your credentials

- **Encryption**: Secrets are encrypted at rest and in transit.
- **Credential substitution**: Supported fill actions resolve placeholders outside the model context.
- **Access control**: Authorized API clients and sessions can use the vault.
- **2FA Support**: Support for two-factor authentication credentials.

## How it works

![vault-fill-action](/images/vault-fill-action.png)

The Vault acts as an intermediary between your code and the browser session.
Attach a vault to a session with `client.Session(vault=vault)` (or its ID, `vault_id=...`), then fill forms with placeholder values (`EMAIL`, `PASSWORD`, `MFA`, ... from `notte_core.credentials`).
When a `fill` or `form_fill` action contains a placeholder, the vault takes over the execution and replaces the dummy value with the actual
credential for the current website, directly inside the browser.

This avoids including the real credential in the placeholder fill action.

## Handling credentials

Use vault placeholders instead of putting real passwords in prompts or source code. Credential substitution happens outside the model context, but the browser still interacts with the destination website. Avoid logging secrets and review what your automation captures or shares.
