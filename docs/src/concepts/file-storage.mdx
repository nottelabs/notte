## How It Works

Files have two sources:

| Source | Purpose | API |
|--------|---------|-----|
| **Uploads** | Files you upload for sessions to use | `storage.upload()` |
| **Downloads** | Files sessions download from websites | `storage.download()` |

```
┌─────────────┐                    ┌──────────────┐
│ Local Files │ ── upload() ─────> │   Uploads    │
└─────────────┘                    └──────┬───────┘
                                         │
                                         v
                                  ┌──────────────┐
                                  │   Session    │
                                  │              │
                                  └──────┬───────┘
                                         │
                                         v
┌─────────────┐                    ┌──────────────┐
│ Local Files │ <── download() ─── │  Downloads   │
└─────────────┘                    └──────────────┘
```

### Attaching a URL directly to a form

In a cloud session, pass a public HTTP(S) file URL, including a signed URL, to
`session.execute(type="upload_file", file_path=...)` along with the upload element's
selector or observed ID. Notte downloads and attaches the file without navigating
away from the form or requiring a separate `session.storage.upload()` call.

<UrlUpload />

The download runs on Notte's servers and does not use browser cookies, browser proxy
settings, or custom authentication headers. URLs must resolve to public addresses,
including after redirects. Files fetched this way are temporary: they are removed
when the session is cleaned up and are not added to the session's file list.

`storage.upload()` only accepts local files; URL support belongs to the browser's
`upload_file` action.

## API Reference

### FileStorage Methods

| Method | Description |
|--------|-------------|
| `upload(file_path, upload_file_name=None)` | Upload a local file to storage |
| `download(file_name, local_dir, force=False)` | Download a file to local directory |
| `list_uploaded_files()` | List files you've uploaded |
| `list_downloaded_files()` | List files downloaded by sessions |

### Parameters

**upload()**
- `file_path` - Path to the local file to upload
- `upload_file_name` - Optional custom name for the uploaded file

**download()**
- `file_id` - ID of the file, from `upload()` or `list()` (`SessionFile.id`)
- `local_dir` - Local directory to save the file (default: current directory)
- `force` - Overwrite an existing local file (default: False)

## Supported File Types

File storage supports all common file types:

- **Documents**: PDF, DOCX, XLSX, TXT, CSV
- **Images**: PNG, JPG, JPEG, GIF, WEBP
- **Archives**: ZIP, RAR, TAR, GZ
- **Media**: MP4, MP3
- **Data**: JSON, XML
