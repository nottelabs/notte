Send a Notte browser screenshot to [watsonx.ai](https://www.ibm.com/products/watsonx-ai) using its REST API. The examples capture `example.com`, exchange an IBM Cloud API key for an IAM token, and request a short image description.

Use a [Notte API key](https://console.notte.cc), an IBM Cloud API key, your watsonx.ai project ID, and a vision-capable model available in that project. See IBM's [API reference](https://cloud.ibm.com/docs/apis/watsonx-ai) for authentication and regional endpoints.

Set `NOTTE_API_KEY`, `WATSONX_API_KEY`, `WATSONX_PROJECT_ID`, and `WATSONX_MODEL_ID`. Set `WATSONX_URL` if your project uses a region other than US South. Only send screenshots you intend to share with IBM.

<Tabs>
  <Tab title="Python">
    Use Python 3.11+ and uv. From [`examples/watsonx`](https://github.com/nottelabs/notte/tree/main/examples/watsonx), run `uv sync --locked`, then `uv run --locked python python/demo.py`.
  </Tab>
  <Tab title="TypeScript">
    Use Node.js 24+. From [`examples/watsonx/typescript`](https://github.com/nottelabs/notte/tree/main/examples/watsonx/typescript), run `npm ci`, then `npm start`.
  </Tab>
</Tabs>

The result includes the model description and session ID. The browser closes on success or failure. See the [example README](https://github.com/nottelabs/notte/tree/main/examples/watsonx) for verification commands.

<Note>Real Notte capture and cleanup are tested with injected IBM responses. Live IBM authentication and model inference remain unverified.</Note>
