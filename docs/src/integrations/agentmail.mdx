[AgentMail](https://agentmail.to) is an email inbox API built for AI agents. Notte [personas](/concepts/personas) can use an AgentMail inbox instead of the default Notte mailbox: set `email_provider="agentmail"` when you create the persona and it gets its own `@agentmail.to` address.

This is useful when your agents sign up for websites. The agent fills the sign-up form with the persona's AgentMail address, the site sends a verification code or link to that inbox, and the agent reads it to finish the flow, with no human in the loop.

Notte creates and manages the AgentMail inbox for you. You don't need an AgentMail account or API key.

## Prerequisites

- A Notte API key ([get one here](https://console.notte.cc))
- The Notte Python SDK (`pip install notte-sdk`), in a version that supports the `email_provider` option

## Create a persona with an AgentMail inbox

Pass `email_provider="agentmail"` when you create the persona. The default is `"notte"`.

<AgentMailPersona />

With the REST API, send `email_provider` to `POST /personas/create`:

<AgentMailCurl />

The persona response includes `email_provider`, so you can check which inbox a persona uses.

## Sign up for a site and verify the email

Attach the persona to an agent. The agent uses the persona's AgentMail address in the sign-up form and reads the verification email from the inbox on its own, exactly as it does with a Notte mailbox.

<AgentMailSignup />

`add_credentials` generates a password for the site and stores it in the persona's vault, so later sessions can log in with the same account. See [Create accounts with Personas](/guides/account_creation) for more on this flow.

## Read emails from the inbox

You can also read the inbox yourself, for example to extract a verification code or link in your own code:

<AgentMailReadEmails />

Each email includes the subject, sender, timestamp, and text and HTML bodies. `email.links()` returns the URLs found in the text body.

## Limitations

- AgentMail inboxes are receive-only. Personas cannot send email.
- Deleting the persona also deletes its AgentMail inbox.
