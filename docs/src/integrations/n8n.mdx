[n8n](https://n8n.io/) is a workflow automation tool. The `n8n-nodes-notte` community node adds Notte scraping and functions as steps between your triggers, branches and downstream integrations without writing code.

## Install the node

In your n8n instance, go to **Settings → Community Nodes → Install** and enter:

```
n8n-nodes-notte
```

Self-hosted instances can install it directly instead:

```bash
npm install n8n-nodes-notte
```

## Add your credentials

Create a **Notte API** credential with an API key from [console.notte.cc](https://console.notte.cc/apikeys). The credential also takes a base URL, which you only need to change if you are pointed at a non-default Notte deployment.

## Nodes

### Notte Agent Browser

For new workflows, use the main node's Scrape or Function mode:

| Mode | What it does |
|------|--------------|
| **Scrape** | Extracts structured data from a URL |
| **Function** | Runs a deployed [Notte function](/concepts/functions) by id |

Use Scrape mode for data from a known URL. Use Function mode for repeatable browser work: author the function once, then call it from your workflows.

The node's legacy Agent mode uses the deprecated hosted agent APIs. For interactive browser work, use [browser sessions](/concepts/sessions), the [CLI](/cli-reference/index) or [MCP](/mcp-server), and deploy repeatable scripts as [Functions](/concepts/functions).

### Notte Trigger

The trigger node starts a workflow when a [persona](/concepts/personas) receives a new email or SMS. This is what closes the loop on signup and verification flows: an agent creates an account, the confirmation email lands in the persona's inbox, and the trigger fires the next branch of your workflow.
