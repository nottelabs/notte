[LangChain](https://python.langchain.com/) loads MCP servers through `langchain-mcp-adapters`, which converts every tool on the server into a LangChain tool. Point it at the [Notte MCP server](/mcp-server) and any LangChain or LangGraph agent can drive a browser.

## Prerequisites

- A Notte API key ([get one here](https://console.notte.cc))
- Credentials for the model your agent uses

## 1. Install the SDKs

```bash
pip install langchain-mcp-adapters langgraph
```

## 2. Attach the Notte MCP server

<Langchain />

Set the following environment variable in your `.env` file:

```bash
NOTTE_API_KEY=your-notte-api-key
```
