[crewAI](https://docs.crewai.com/) gives every agent in a crew a set of tools. `MCPServerAdapter` turns an MCP server into those tools, so pointing it at the [Notte MCP server](/mcp-server) hands your crew a real browser.

## Prerequisites

- A Notte API key ([get one here](https://console.notte.cc))
- Credentials for the model your crew uses

## 1. Install the SDKs

```bash
pip install "crewai-tools[mcp]"
```

## 2. Attach the Notte MCP server

<Crewai />

Set the following environment variable in your `.env` file:

```bash
NOTTE_API_KEY=your-notte-api-key
```

<Note>
  `MCPServerAdapter` is a context manager. Build your crew inside the `with` block so the tools stay connected for the whole run.
</Note>
