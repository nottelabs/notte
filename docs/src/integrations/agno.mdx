[Agno](https://docs.agno.com/) ships an `MCPTools` toolkit that connects an agent to any MCP server. Point it at the [Notte MCP server](/mcp-server) to give your agent sessions, browser agents, scraping and functions.

## Prerequisites

- A Notte API key ([get one here](https://console.notte.cc))
- Credentials for the model your agent uses

## 1. Install the SDKs

```bash
pip install agno mcp
```

## 2. Attach the Notte MCP server

<Agno />

Set the following environment variable in your `.env` file:

```bash
NOTTE_API_KEY=your-notte-api-key
```

<Note>
  Pass the bearer token through `header_provider`, not `headers` - `MCPTools` forwards `header_provider` to the HTTP transport and rejects a bare `headers` argument.
</Note>
