Connect [Stagehand](https://github.com/browserbase/stagehand) to your Notte session
to act on pages, extract structured data, and observe available actions.

## Setup

Set `NOTTE_API_KEY` and `ANTHROPIC_API_KEY` in your environment.

- **Python 3.11+:** install `notte-sdk` and `stagehand==4.2.1`.
- **TypeScript, Node.js 22.18+:** install `notte-sdk`, `@browserbasehq/stagehand@4.2.1`, and `zod`.

## Connect and extract

Pass the session's CDP URL to Stagehand. This example opens a page and extracts
its heading into a typed schema. Both SDKs close their connections before the
Notte session stops.

<StagehandConnect />

You can also call `stagehand.act()` and `stagehand.observe()` on the connected browser.
Use your own model provider key; a Browserbase account is not required.

<Note>
  This integration targets Stagehand 4.2.1. Browserbase-managed services and
  experimental callback batches are not supported.
</Note>
