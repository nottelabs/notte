Kernel provides cloud browsers that expose a Chrome DevTools Protocol (CDP) endpoint. Connect a Notte session to that endpoint to observe pages, execute actions, and scrape content.

## Connect a Kernel browser

1. Install the `notte-sdk` and `kernel` Python packages in your environment.
2. Create a browser using your Kernel account and obtain its `cdp_ws_url`. See the [Kernel documentation](https://docs.onkernel.com/) for browser provisioning and authentication.
3. Pass that URL as `cdp_url` when creating your Notte session. Replace the external-provider URL in this shared CDP example with the URL of your Kernel browser:

<ExternalBasic />

The same session supports `observe`, `execute`, and `scrape`. For more connection options, see [External Providers](/features/sessions/external-providers).

## Browser ownership

The Notte session context manages its own connection. Keep the Kernel browser ID and delete the browser through Kernel when your automation finishes, including when it raises an error. Only delete browsers created by your automation.
