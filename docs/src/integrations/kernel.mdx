Kernel.sh is a developer platform that provides browser infrastructure for web automation. By integrating with Notte, you can use Kernel browser infra to run reliable browser automations using Chrome DevTools Protocol (CDP).

## Adding Kernel to existing Notte implementations

### 1. Install Notte and Kernel SDK

Install the `notte-sdk` and `kernel` packages in your Python environment.

### 2. Create and connect a browser

Use Kernel's `cdp_ws_url` as the `cdp_url` when starting a Notte session. Configure proxies, launch arguments, and viewport with Kernel before connecting.

<KernelSession />

The Notte context manager stops the Notte session. The `finally` block separately deletes the browser owned by Kernel, including when the automation fails.
