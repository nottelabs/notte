[Google ADK](https://google.github.io/adk-docs/) loads external tools through `McpToolset`. Point it at the [Notte MCP server](/mcp-server) and your agent gets the full Notte toolset - sessions, browser agents, scraping, functions, vaults and personas - with no wrapper code to maintain.

## Prerequisites

- A Notte API key ([get one here](https://console.notte.cc))
- Credentials for the model your ADK agent uses

## 1. Install the SDKs

```bash
pip install google-adk
```

## 2. Attach the Notte MCP server

Notte's MCP server speaks streamable HTTP and authenticates with a bearer token:

<GoogleAdk />

Set the following environment variable in your `.env` file:

```bash
NOTTE_API_KEY=your-notte-api-key
```
