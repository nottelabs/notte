[traceroot](https://traceroot.ai) is the open-source platform that continuously improves your AI agents using evidence from production. It works in four steps: trace your agent, detect the runs that miss the mark, investigate signals to find the fix, and verify it with evals.

The [runnable examples](https://github.com/nottelabs/notte/tree/main/examples/traceroot) give an agent a Notte browser through [Notte Browser MCP](/mcp-server) and ask it for the top Hacker News stories with their points. This guide walks through each step on them.

## Trace

See each model call, tool call, and response, with inputs, outputs, latency, and cost.

Get keys from [Notte](https://console.notte.cc/apikeys), your model provider, and your project in [traceroot](https://app.traceroot.ai). If you [self-host traceroot](https://traceroot.ai/docs/developer/self-hosting), also set `TRACEROOT_HOST_URL` to your API's origin. Clone the Notte repository and open `examples/traceroot`.

<Tabs>
  <Tab title="OpenAI Agents SDK">
    Use Python 3.11 to 3.13 and uv. Set `NOTTE_API_KEY`, `OPENAI_API_KEY`, and `TRACEROOT_API_KEY`, then run `uv sync --locked` and `uv run python hn_openai.py`.

    ```python
    traceroot.initialize(integrations=[Integration.OPENAI_AGENTS])
    ```

    Keep the Agents SDK's tracing on: `RunConfig(tracing_disabled=True)` drops the agent's spans. traceroot replaces the SDK's default trace exporter, so the spans go to traceroot instead of OpenAI.
  </Tab>
  <Tab title="Claude Agent SDK">
    Use Python 3.11 to 3.13 and uv. Set `NOTTE_API_KEY`, `ANTHROPIC_API_KEY`, and `TRACEROOT_API_KEY`, then run `uv sync --locked` and `uv run python hn_claude.py`.

    ```python
    import claude_agent_sdk

    traceroot.initialize(integrations=[Integration.CLAUDE_AGENT_SDK])
    ...
    async for message in claude_agent_sdk.query(prompt=prompt, options=OPTIONS):
        ...
    ```

    traceroot wraps `claude_agent_sdk.query`. Call it through the module: a `query` imported by name before `initialize()` is not traced.
  </Tab>
  <Tab title="Vercel AI SDK">
    Use Node.js 24+. Set `NOTTE_API_KEY`, `ANTHROPIC_API_KEY`, and `TRACEROOT_API_KEY`, then run `npm ci` and `npm start` in `typescript`.

    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';
    import { OpenTelemetry } from '@ai-sdk/otel';
    import { registerTelemetry } from 'ai';

    TraceRoot.initialize();
    registerTelemetry(new OpenTelemetry({ usage: true }));
    ```
  </Tab>
</Tabs>

Each example wraps the run in a `hacker_news.top_stories` span, groups it under the Notte session ID, and prints the stories and the trace ID. Under that span, each step shows the model call with its tokens and cost, then the Notte tool the agent called, such as `browser_action`, `browser_observe`, or `browser_scrape`, with what the browser returned. Read the trace from your terminal with the [traceroot CLI](https://traceroot.ai/docs/cli/get-started):

```bash
npx -y traceroot-cli@latest login --api-key "$TRACEROOT_API_KEY"
npx -y traceroot-cli@latest traces get <trace_id>
```

## Detect

Define what good behavior looks like. [Detectors](https://traceroot.ai/docs/detectors/introduction) use LLM judges to flag runs that miss the mark.

For a browser agent, a useful check is whether the answer is grounded in what the browser returned. Create a detector from the **Hallucination** template, set sampling to 100%, and use this prompt:

```text
This trace is a browser agent that reads Hacker News through Notte browser tools
(browser_action, browser_observe, browser_scrape). Its final answer lists stories with a title and points.

A story is backed by the page if its title and points appear in the output of a Notte browser tool span in this trace.

Report identified=true if any story in the final answer is not backed by the page: no browser tool output in the
trace shows it, or its title or points differ from what the tool returned. Report identified=false if every story
matches browser tool output.
```

To see it flag a run, use `uv run python hn_openai.py --broken`. The flag introduces a prompt regression: the instructions tell the agent to skip scraping and answer from memory, so it returns stories that aren't on Hacker News. The detector records a finding on each of those runs and none on the normal runs of the three examples.

## Signals

traceroot groups findings of the same problem into a [signal](https://traceroot.ai/docs/signals/introduction), and the [traceroot Agent](https://traceroot.ai/docs/ai-agent/overview) investigates it.

For the prompt regression, the root cause analysis found the cause from the trace alone: the "don't scrape it: answer from what you know" instruction, browser tools that were listed but never called, and stories taken from the model's training data. It recommended removing the instruction and requiring a `browser_scrape` or `browser_observe` call before the final answer. Connect GitHub in traceroot's settings so the agent can also investigate your code and pinpoint the fix down to the commit, file, and line.

## Verify

Run [evals](https://traceroot.ai/docs/evals/introduction) against your datasets and compare versions to measure improvements and catch regressions.

`hn_eval.py` evaluates the OpenAI agent on three Hacker News tasks. Its scorer, `backed_by_front_page`, checks each returned story against the live front page from the Hacker News API and scores the share that matches.

```bash
uv run python hn_eval.py --broken   # with the prompt regression
uv run python hn_eval.py            # after the fix
```

Both runs are recorded against the same dataset, so you can compare them case by case. The version with the regression scores 0 on every case. The fixed version scores 1 on each case where every story is on the front page. If Hacker News rate-limits the browser, the agent can return no stories or placeholder stories instead of an error; that case scores 0, and the eval shows you which run to inspect.
