Use the [1Password SDK](https://www.1password.dev/sdks) to read login fields and fill them in a Notte browser. The Python and TypeScript examples submit a test form without printing the field values.

## Set up

Create a [1Password service account](https://start.1password.com/developer-tools/infrastructure-secrets/serviceaccount/) with read access to a test vault containing a dummy Login item. Set `OP_SERVICE_ACCOUNT_TOKEN`, `OP_USERNAME_REF`, and `OP_PASSWORD_REF`. Field references use `op://vault/item/field`; see [1Password's reference syntax](https://www.1password.dev/sdks/load-secrets).

Set `NOTTE_API_KEY` from [Notte](https://console.notte.cc/apikeys), then clone the [Notte repository](https://github.com/nottelabs/notte) and open [examples/onepassword](https://github.com/nottelabs/notte/tree/main/examples/onepassword). Its README includes the installation commands.

<Tabs>
  <Tab title="Python">
    Use Python 3.11+ and uv. Run `uv sync --locked`, then `uv run python python/demo.py`.
  </Tab>
  <Tab title="TypeScript">
    Use Node.js 24+. Open `typescript`, run `npm ci`, then `npm start`.
  </Tab>
</Tabs>

## Use your login page

The example fills and submits an in-memory test form. Reuse its `fill_login` or `fillLogin` helper on your page and adapt the labeled field and button locators. It resolves only the two supplied references.

Each attempt owns its Notte browser and closes it after success or failure. The result includes the session ID and submission status.
