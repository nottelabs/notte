A secret proxy keeps real secrets out of the browser. Your tokenization provider gives you stand-in values, the agent types them, and your proxy replaces them with the real values on requests to the hosts you list. Every other host stays on the session's normal proxy.

Use one of these options:

<CardGroup cols={3}>
  <Card title="Evervault" icon="shield-halved" href="/features/sessions/secret-proxies/evervault">
    Fill Evervault Browser Tokens.
  </Card>
  <Card title="VGS" icon="vault" href="/features/sessions/secret-proxies/vgs">
    Reveal VGS aliases through its outbound proxy.
  </Card>
  <Card title="Custom proxy" icon="server" href="/features/sessions/secret-proxies/custom-proxy">
    Run your own secret proxy.
  </Card>
</CardGroup>

See [Secret Proxies](/features/sessions/secret-proxies/overview) for the request fields, the rules, response masking and the shared exit IP, and [Passwords, 2FA codes and API keys](/features/sessions/secret-proxies/credentials) for logins and other secrets.
