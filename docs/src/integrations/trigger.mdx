Use [Trigger.dev](https://trigger.dev/) to schedule and retry browser tasks. The runnable TypeScript example in `examples/trigger` in the [Notte repository](https://github.com/nottelabs/notte) connects Playwright to a Notte cloud browser and returns the page title.

## Set up

Use Node.js 24+, a [Notte API key](https://console.notte.cc/apikeys), and a [Trigger.dev project](https://cloud.trigger.dev).

```bash
git clone https://github.com/nottelabs/notte.git
cd notte/examples/trigger
npm ci
```

Set the keys and project reference from your Trigger.dev dashboard:

```bash
export NOTTE_API_KEY=your-notte-api-key
export TRIGGER_PROJECT_REF=your-project-reference
export TRIGGER_SECRET_KEY=your-development-api-key
npm run dev
```

The CLI prompts you to log in. For non-interactive use, set `TRIGGER_ACCESS_TOKEN` from your [personal access tokens](https://cloud.trigger.dev/account/tokens).

## Run a browser task

In your project's development dashboard, test `notte-read-page` with this payload:

```json
{"url":"https://example.com"}
```

The result contains `title: "Example Domain"` and the stopped session's `session_id`. Each attempt creates its own session and closes it when the handler returns or raises an error. The example retries up to three times and performs only page reads. Keep operations with external side effects out of automatic retries unless they are idempotent.

For deployment, follow [Trigger.dev's deployment guide](https://trigger.dev/docs/deploy) and configure `NOTTE_API_KEY` in the target environment. No local browser installation is needed.
