Two `observe()` options are deprecated and will be **removed on December 1, 2026**:

- `perception_type="deep"`
- `instructions`

Until then both keep working exactly as before. Requests that use them already receive `Deprecation`, `Sunset` and `Link` response headers, and the Python and TypeScript SDKs emit a deprecation warning. After December 1, 2026 the API rejects requests that use either option.

## Deep perception → fast perception

Remove `perception_type="deep"` from `observe()` calls and from the session options, or set it to `"fast"`, the default. In Python, `session.observe(perception_type="deep")` becomes `session.observe()`; in TypeScript, `session.observe({ perception_type: 'deep' })` becomes `session.observe()`.

Fast perception lists the page's actions with their IDs and selectors. It does not add the LLM-written page description, action descriptions and categories that deep perception added.

## Observe instructions

Use [`session.act(instruction)`](/features/sessions/act) instead. It observes the page, picks the action that carries out the instruction and runs it, so `session.observe(instructions="...")` followed by `session.execute(...)` becomes `session.act("...")`. `act()` runs on local sessions of the Python SDK (`notte.Session`, with `pip install "notte[llm]"`); `session.choose()` and `session.check()` answer typed questions about the page.

Cloud sessions (`client.Session`) and the TypeScript SDK do not run `act()` yet. There, call `observe()` without `instructions` and pick the next action from the actions it returns, for example by passing them to your own LLM: in Python, choose among `observation.space.actions` and pass the chosen action to `session.execute(action)`; in TypeScript, execute it by its type and ID, for example `session.execute({ type: 'click', id: 'B1' })`, or build it with the typed action helpers (`actions.fill({ ... })`).

## Response headers

Responses to observe requests that use either option carry:

| Header | Value |
| --- | --- |
| `Deprecation` | `@1792454400` (October 20, 2026) |
| `Sunset` | `Tue, 01 Dec 2026 00:00:00 GMT` |
| `Link` | `<https://docs.notte.cc/features/sessions/observe-migration>; rel="deprecation"` |

If you call the API directly, you can log these headers to find the remaining calls in your code.
