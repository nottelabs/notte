Notte sessions include built-in stealth features to help your automations avoid detection by anti-bot systems.

## Built-in Stealth Features

All Notte sessions automatically include:

- **Coherent browser fingerprint** - A realistic, recent Chrome desktop fingerprint (user agent, platform, screen, and graphics hardware) that stays internally consistent
- **Location matching** - Timezone, locale, and geolocation follow the session's proxy exit IP
- **Residential proxies** - On by default (`proxies=True`). See [Proxies](/features/sessions/proxies)
- **Captcha solving** - On by default (`solve_captchas=True`). See [CAPTCHA Solving](/features/sessions/captcha-solving)

## Basic Usage

Stealth features are enabled by default. Simply create a session:

<CodeGroup>
  ```python Python
  from notte_sdk import NotteClient

  client = NotteClient()

  with client.Session() as session:
      page = session.page
      page.goto("https://example.com")
      # Stealth features automatically active
  ```
</CodeGroup>

## Proxy Location

Residential proxies are on by default and exit in the US. Pick a country to match your target site; the fingerprint's timezone and locale follow it:

<CodeGroup>
  ```python Python
  from notte_sdk import NotteClient

  client = NotteClient()

  with client.Session(proxies="fr") as session:
      page = session.page
      page.goto("https://example.com")
  ```
</CodeGroup>

## Advanced Stealth

For sites with sophisticated bot detection, `advanced_stealth=True` runs the session in Notte's highest-fidelity browser environment. It is available to approved workspaces; contact [hello@notte.cc](mailto:hello@notte.cc) to enable it.

<CodeGroup>
  ```python Python
  from notte_sdk import NotteClient

  client = NotteClient()

  with client.Session(advanced_stealth=True) as session:
      page = session.page
      page.goto("https://example.com")
  ```
</CodeGroup>

## Custom User Agents

Override the default user agent for specific requirements. Note that a custom user agent replaces the one Notte generates to match the rest of the fingerprint:

<CodeGroup>
  ```python Python
  from notte_sdk import NotteClient

  client = NotteClient()

  with client.Session(
      user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
  ) as session:
      page = session.page
      page.goto("https://example.com")
  ```
</CodeGroup>

## Testing Stealth

Test your stealth configuration against detection services:

<CodeGroup>
  ```python Python
  from notte_sdk import NotteClient

  client = NotteClient()

  test_sites = [
      "https://bot.sannysoft.com/",
      "https://arh.antoinevastel.com/bots/areyouheadless",
      "https://fingerprint.com/demo/"
  ]

  with client.Session(proxies=True) as session:
      page = session.page

      for site in test_sites:
          page.goto(site)
          page.screenshot(path=f"stealth_test_{site.split('//')[1].split('/')[0]}.png")
  ```
</CodeGroup>

## What Stealth Can't Do

Stealth features help avoid detection, but they cannot:

- ❌ Bypass login rate limits (use delays between attempts)
- ❌ Avoid behavioral analysis (act like a human)
- ❌ Bypass IP-based blocking (use proxy rotation)
- ❌ Solve all captchas automatically (use captcha solving)

## Stealth + Captcha Solving

Combine stealth with automatic captcha solving for comprehensive protection:

<CodeGroup>
  ```python Python
  from notte_sdk import NotteClient

  client = NotteClient()

  with client.Session(
      solve_captchas=True,
      proxies=True
  ) as session:
      page = session.page
      page.goto("https://example.com/login")
      # Both stealth and captcha solving active
  ```
</CodeGroup>
