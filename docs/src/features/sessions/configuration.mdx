Sessions are isolated browser instances running in the cloud that you can control programmatically. Each session provides a Playwright-compatible page that you can automate using familiar browser automation APIs.

## Quick Start

Create a session with default settings:

<QuickStart />

Active sessions can be viewed and managed in the [Sessions](https://console.notte.cc/sessions) page in the console.

<Tip>
  Sessions are automatically stopped when exiting the context manager. Always use the `with` statement to ensure proper cleanup.
</Tip>

## Configuration Options

Customize your session with these options:

<FullConfig />

### Common Parameters

<ParamField path="advanced_stealth" type="boolean" default={false}>
  Enable Notte's highest-fidelity browser environment for sites with sophisticated bot detection. Access is currently available to approved workspaces; contact [hello@notte.cc](mailto:hello@notte.cc) to enable it.
</ParamField>

<ParamField path="solve_captchas" type="boolean" default={true}>
  Automatically detect and solve captchas (reCAPTCHA, hCaptcha, etc.). Set this option on the session request.
  The retired global `solve_captchas` TOML key is ignored with a warning.
</ParamField>

<ParamField path="block_ads" type="boolean" default={true}>
  Block ads and trackers in managed browsers using Basic filtering, without cosmetic filtering or injected scriptlets.
  To opt out, use `client.Session(block_ads=False)` in Python or `client.Session({ block_ads: false })` in TypeScript.
  When omitted, the SDK leaves the setting to the API default. Explicit values require an API that supports `block_ads`.
  This setting does not configure local browsers or externally connected CDP browsers.
</ParamField>

<ParamField path="proxies" type="boolean | string | list[ProxySettings]" default={true}>
  Residential proxies are enabled by default. Set to `false` to disable them or provide custom proxy configuration.
  See [Proxy Configuration](#proxies) for details.
</ParamField>

<ParamField path="idle_timeout_minutes" type="integer" default={3}>
  Idle timeout in minutes (max: 30). The session closes after this long without any operation; each operation resets it. Cannot exceed `max_duration_minutes`. `timeout_minutes` is accepted as a legacy alias.
</ParamField>

<ParamField path="max_duration_minutes" type="integer" default={15}>
  Maximum session lifetime in minutes (max: 1440), regardless of activity.
</ParamField>

<ParamField path="viewport_width" type="integer">
  Browser viewport width in pixels (minimum 500). Set together with `viewport_height`. When neither is set, Notte picks a viewport around 1280x1080.
</ParamField>

<ParamField path="viewport_height" type="integer">
  Browser viewport height in pixels (minimum 500). Set together with `viewport_width`.
</ParamField>

<ParamField path="aspect_ratio" type="string">
  Viewport shape preset: `"5:4"` or `"16:9"`. Notte fits the largest viewport of this shape in the available screen area. Cannot be combined with `viewport_width`/`viewport_height`.
</ParamField>

### Advanced Parameters

<ParamField path="user_agent" type="string">
  Custom user agent string for the browser session.
</ParamField>

<ParamField path="chrome_args" type="list[str]">
  Custom Chrome/Chromium launch arguments. Advanced use only.
</ParamField>

<ParamField path="cdp_url" type="string">
  Connect to an external browser session via Chrome DevTools Protocol URL (e.g., from Kernel.sh or other providers). Proxies, `user_agent`, `chrome_args`, and the viewport must be configured with the external provider, so leave them unset (proxies default to off when `cdp_url` is set).
</ParamField>

<ParamField path="extra_http_headers" type="dict[str, str]">
  Extra HTTP headers sent with every request.
</ParamField>

<ParamField path="profile" type="SessionProfile">
  Browser profile to load, with `persist=True` to save state back on close. See [Browser Profiles](/features/sessions/browser-profiles).
</ParamField>

<ParamField path="vault_id" type="string">
  Vault whose credentials the session can use. See [Vaults](/concepts/vaults).
</ParamField>

<ParamField path="web_bot_auth" type="boolean" default={false}>
  Sign requests with Web Bot Auth. See [Cloudflare Web Bot Auth](/features/sessions/cloudflare-web-bot-auth).
</ParamField>

<ParamField path="cookie_file" type="string | Path">
  Path to a JSON file for automatic cookie loading at session start and saving at session end.
</ParamField>

<ParamField path="storage" type="RemoteFileStorage">
  Attach a file storage instance to the session for file operations. Python creates `session.storage` automatically when this is omitted. In TypeScript, create `client.FileStorage()` and pass it here before using storage.
</ParamField>

<ParamField path="perception_type" type="string" default="fast">
  Default perception type for observations: `"fast"` (simple) or `"deep"` (LLM-powered). `"deep"` is deprecated and will be removed on December 1, 2026; use `"fast"`. See the [observe migration guide](/features/sessions/observe-migration).
</ParamField>

<ParamField path="raise_on_failure" type="boolean" default={true}>
  Raise exceptions when action execution fails instead of returning error results.
</ParamField>

## Managed Auth

<ParamField path="auth_ids" type="list[str]">
  Up to 10 Managed Auth connection IDs to verify and, when needed, log in inside the session. While login runs, the session status is `authenticating`.
</ParamField>

<ParamField path="wait_for_authentication" type="boolean" default={true}>
  SDK option. When true, starting the session waits until authentication is ready. When false, call `session.wait_for_auth()` before browser actions.
</ParamField>

<ParamField path="auth_retry" type="integer" default={0}>
  Additional retries (0 to 2) for transient Managed Auth login failures.
</ParamField>
