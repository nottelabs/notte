Notte can automatically detect and solve captchas including reCAPTCHA v2, hCaptcha, Cloudflare Turnstile, press-and-hold challenges, and simple text challenges during your browser automation. Captcha solving is on by default (`solve_captchas=True`).

Captcha solving is enabled by default. You can set it explicitly when creating a session:

## Supported CAPTCHA Types

Notte automatically detects and solves:

- ✅ **reCAPTCHA v2** - Checkbox and image challenges
- ✅ **hCaptcha** - Checkbox and image challenges
- ✅ **Cloudflare Turnstile**
- ✅ **Press-and-hold challenges**
- ✅ **Text CAPTCHAs** - Simple "read the characters and type them" challenges

## How It Works

When captcha solving is enabled:

1. **Detection** - Notte monitors the page for captcha elements
2. **Solving** - Captchas are solved automatically in the background
3. **Continuation** - Your automation continues seamlessly

No additional code is needed - captchas are solved automatically when encountered.

Combine captcha solving with proxies for better success rates:

Residential proxies and CAPTCHA solving are both on by default. Use [Proxies](/features/sessions/proxies) to choose a location or supply a custom proxy.

### Waiting for a solve in Python

The Python SDK polls one ongoing solve through short HTTP requests. Repeated
`captcha_solve` calls join that solve or return its completed result. Configure the
total wait separately from ordinary action timeouts:

Set `captcha_timeout_seconds=180` when constructing `NotteClient`. Then use the `captcha_solve` action shown above; do not restart the session to wait for the same challenge.

The default CAPTCHA wait is three minutes. A terminal solver failure, page change,
or expired wait budget follows the usual `raise_on_failure` behavior. Polling does
not restart the solve or extend the session's maximum lifetime.

SDK actions blocked before execution wait for the CAPTCHA and then retry. If an
action already executed and triggered a CAPTCHA, the SDK waits without replaying
it. This coordination applies to Python SDK actions; direct Playwright/CDP calls
do not participate. It requires a backend version that supports CAPTCHA polling.

### Text CAPTCHAs

Text CAPTCHAs are the old-school challenges that show distorted letters, numbers, or a short phrase and ask the user to type the answer into a field. For these challenges, use `captcha_type="text"`. ## Limitations

### What CAPTCHA Solving Can Do:
- ✅ Solve most reCAPTCHA v2 challenges
- ✅ Solve most hCaptcha challenges
- ✅ Solve Cloudflare Turnstile and press-and-hold challenges
- ✅ Solve simple text CAPTCHA challenges
- ✅ Work with residential proxies
- ✅ Work in remote browser sessions

### What It Cannot Do:
- ❌ Solve 100% of captchas (some are unsolvable)
- ❌ Reliably solve heavily distorted or ambiguous text challenges
- ❌ Solve custom/proprietary captcha systems
- ❌ Bypass all bot detection (combine with stealth)
