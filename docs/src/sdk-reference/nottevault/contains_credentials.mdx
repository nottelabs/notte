---
title: "contains_credentials"
description: "Check if the action contains credentials"
---



A value holds a credential only if it is exactly a placeholder (ignoring surrounding whitespace), or a
value already replaced by the vault. Only fill-type actions carry credentials.



## Parameters

<ParamField path="action" type="BaseAction" required>
  The action to check for credentials
</ParamField>

## Returns

`bool`:     True if the action contains credential placeholders, False otherwise
