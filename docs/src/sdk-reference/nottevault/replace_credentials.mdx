---
title: "replace_credentials"
description: "Replace credentials in the action with actual values from the vault"
---



Values that were already replaced (`ValueWithPlaceholder`) and form values that do not contain any
placeholder are left untouched.



## Parameters

<ParamField path="action" type="BaseAction" required>
  The action to replace credentials in
</ParamField>

<ParamField path="attrs" type="LocatorAttributes" required>
  Locator attributes for validation
</ParamField>

<ParamField path="snapshot" type="BrowserSnapshot" required>
  Browser snapshot containing URL information
</ParamField>

## Returns

<Visibility for="humans">[`BaseAction`](/sdk-reference/misc/baseaction)</Visibility><Visibility for="agents">[`BaseAction`](/sdk-reference/misc/baseaction.md)</Visibility>:     Modified action with replaced credentials

## Raises

- `ValueError`: If the action type is not supported
- `CredentialReplacementError`: If a placeholder cannot be replaced (e.g. missing credential field)
- `NoCredentialsFoundError`: If the vault holds no credentials for the current page
