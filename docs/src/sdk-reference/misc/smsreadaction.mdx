Not a browser action: read the persona inbox directly instead.

**Example:**
```python
import datetime as dt

sms = persona.sms(limit=10, only_unread=True)
sms = persona.wait_for_sms(timedelta=dt.timedelta(minutes=5), timeout=120)
```
