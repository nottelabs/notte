```python
function = notte.Function("<your-function-id>")
function.set_deletion_protection(True)
print(function.response.deletion_protected)
```

While deletion protection is on, the function cannot be deleted. Any workspace member's key can
turn it on. Turning it off takes the key of a workspace admin or owner.
