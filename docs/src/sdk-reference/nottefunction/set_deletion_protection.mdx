---
title: "set_deletion_protection"
description: "Turn deletion protection on or off"
---
import AgentMdNotice from '/partials/agent-md-notice.mdx';

<AgentMdNotice />

While it is on, the function cannot be deleted.

```python
function = notte.Function("<your-function-id>")
function.set_deletion_protection(True)
print(function.response.deletion_protected)
```

Any workspace member's key can turn it on. Turning it off takes the key of a
workspace admin or owner


## Parameters

<ParamField path="enabled" type="bool" required>
</ParamField>

## Returns

`None`
