## Parameters

You can use the default parameters to create your agent, or customize them:

<ParamField path="session" type="UnionType[RemoteSession, None]" default="None">
  The session the agent runs in. Required to create a new agent; only omit it when you pass `agent_id` to load an existing agent. The session's `open_viewer` parameter controls whether to display a live viewer.
</ParamField>

<ParamField path="vault" type="UnionType[NotteVault, None]" default="None">
  A notte vault instance, if the agent requires authentication
</ParamField>

<ParamField path="notifier" type="UnionType[BaseNotifier, None]" default="None">
  A notifier (for example, email), which will get called upon task completion.
</ParamField>

<ParamField path="persona" type="UnionType[NottePersona, None]" default="None">
</ParamField>

<ParamField path="agent_id" type="UnionType[str, None]" default="None">
  The ID of an existing agent to load instead of creating a new one.
</ParamField>

<ParamField path="reasoning_model" type="notte_core.common.config.LlmModel | str">
  The language model to use for agent reasoning.
</ParamField>

<ParamField path="use_vision" type="bool" default="True">
  Whether to enable vision capabilities for the agent. Not all reasoning models support vision.
</ParamField>

<ParamField path="max_steps" type="int" default="20">
  Maximum number of steps the agent can take, from 1 to 150.
</ParamField>

<ParamField path="vault_id" type="str | None">
  Optional ID of the vault to use.
</ParamField>

<ParamField path="persona_id" type="str | None">
</ParamField>

<ParamField path="notifier_config" type="dict[str, typing.Any] | None">
  Config used for the notifier.
</ParamField>

## Run parameters

`agent.run()` and `agent.start()` accept:

<ParamField path="task" type="str" required>
  The task description to execute.
</ParamField>

<ParamField path="url" type="str | None" default="None">
  Optional URL to start the task from.
</ParamField>

<ParamField path="response_format" type="type[BaseModel] | None" default="None">
  The format of the agent answer. You can use a Pydantic model or a JSON Schema dict.
</ParamField>

<ParamField path="session_offset" type="int | None" default="None">
  Experimental. The session step from which the agent gathers context. If omitted, the agent starts with fresh memory.
</ParamField>
