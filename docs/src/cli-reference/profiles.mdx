## `notte profiles cookies-set`

Import cookies into a profile from a JSON file.

The file may be a bare array of cookies, which is what Playwright and the Chrome extensions export, or an object with a `cookies` key.

| Flag | Description |
| - | - |
| `--file <string>` | Path to a cookies JSON file (required) |
| `--mode <string>` | replace the profile's cookies, or append to them |
| `--profile-id <string>` | Profile ID (required) |
| `--source-format <string>` | Format the cookies were exported in (playwright, chrome) |

## `notte profiles sync`

Read the cookies from a local Firefox, Chrome, Brave, Edge, Chromium, Arc or Helium profile and upload them into a Notte cloud profile, so remote sessions and agents start already logged in. Arc and Helium are supported on macOS only.

Cookies are read from a copy of the browser's own files on this machine and decrypted locally. Nothing leaves your computer until you confirm the upload, and with `--domain` you choose exactly which sites are included.

With `--profile-id` the cookies go into an existing profile; without it a new profile is created and its id is printed for you to reuse next time.

| Flag | Description |
| - | - |
| `--browser <string>` | Browser to read from (firefox, chrome, brave, edge, chromium, arc, helium) |
| `--domain <strings>` | Only sync cookies for these domains and their subdomains (repeatable) |
| `--local-profile <string>` | Local browser profile, by name or directory (prompts if there is more than one) |
| `--mode <string>` | How to apply the cookies: replace the profile's cookies, or append to them (default: `replace`) |
| `--name <string>` | Name for the new profile when `--profile-id` is omitted |
| `--profile-id <string>` | Existing Notte profile to sync into (creates a new one if omitted) |
