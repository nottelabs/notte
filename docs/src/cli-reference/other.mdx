## `notte clear`

Clear all locally stored state including current session, viewer URL, and function. This does not affect credentials or settings.

## `notte health`

Check if the Notte API is healthy and responding.

## `notte search <query>`

Search the web via the Notte search API.

Returns either a list of search results, or an LLM-generated answer with sources, depending on `--output-type`.

Examples:

```bash
notte search "what is anthropic"
notte search what is anthropic
notte search "latest llm releases" --depth deep
notte search "what is anthropic" --output-type sourcedAnswer
```

| Flag | Description |
| - | - |
| `--depth <string>` | Search depth: standard, fast, or deep |
| `--output-type <string>` | Output type: searchResults, sourcedAnswer, or structured |

## `notte upgrade`

Upgrade the CLI to the latest release.

Uses Homebrew when the CLI was installed with Homebrew. Otherwise it re-runs the install script (https://notte.cc/install-cli.sh), replacing the binary that is running. On Windows it prints the manual steps instead.

## `notte version`

Print version information
