Upload, list, and download files owned by a browser session.

## `notte files download <file-id>`

Download a user upload or browser download by its immutable file ID.

| Flag | Description |
| - | - |
| `--path <string>` | Output file path (defaults to current directory) |
| `--session-id <string>` | Session ID (uses current session if not specified) |

## `notte files list`

List all files owned by a browser session. Use `--from` uploads or `--from` session to filter the source.

| Flag | Description |
| - | - |
| `--from <string>` | File source: uploads or session (default all) |
| `--session-id <string>` | Session ID (uses current session if not specified) |

## `notte files upload <file-path>`

Upload a file to a browser session.

| Flag | Description |
| - | - |
| `--session-id <string>` | Session ID (uses current session if not specified) |
