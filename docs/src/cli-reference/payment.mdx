## `notte payment connect`

Return a Link wallet connection URL and phrase. Open the URL to authorize Notte. Completion is detected in the background; this command does not wait. Run it again to retrieve the pending link or confirm connected. No browser session is required.

| Flag | Description |
| - | - |
| `--mode <string>` | Wallet mode: test or live (defaults to the API setting) |

## `notte payment disconnect`

Revoke and forget the selected wallet connection, then use payment connect to choose another account. The other mode is unaffected. Active payments and card cleanup must finish first.

| Flag | Description |
| - | - |
| `--mode <string>` | Wallet mode: test or live (defaults to the API setting) |

## `notte payment request`

Request spending from a connected wallet and receive approval instructions

| Flag | Description |
| - | - |
| `--amount <string>` | Amount in currency units (100.91 = USD 100.91). Required. |
| `--currency <string>` | Three-letter lowercase currency (default: `usd`) |
| `--description <string>` | Purchase description (100 to 4000 characters). Required. |
| `--idempotency-key <string>` | Reuse this key with the same request to recover a previous attempt |
| `--merchant-name <string>` | Merchant name. Required. |
| `--merchant-url <string>` | HTTPS merchant URL. Required. |
| `--mode <string>` | Payment mode: test or live (defaults to the API setting) |
| `--session-id <string>` | Existing browser session ID. Required. |

## `notte payment status PAYMENT_ID`

Retrieve payment status and current approval instructions

## `notte payment wait PAYMENT_ID`

Wait until the temporary card is installed in the session vault. Ready does not mean a purchase succeeded. Connection, approval, and verification instructions appear on stderr. Exiting does not cancel provisioning.

| Flag | Description |
| - | - |
| `--wait-timeout <duration>` | Maximum time to wait (e.g. 10m); zero waits until completion |
