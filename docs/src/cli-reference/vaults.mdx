## `notte vaults credentials add`

Add credentials (password and optional MFA secret) to a vault.

Security note: values passed via `--password` and `--mfa-secret` are read from argv, which makes them visible in 'ps' output and process snapshots while the command runs. Expanding them from an environment variable keeps the literal value out of your shell history, but the shell still passes it to notte as an argument:

```bash
notte vaults credentials add --vault-id <id> --url <url> \
  --email me@example.com --password "$MY_PASSWORD"
```

Example values shown in the docs (e.g. EXAMPLEMFASECRET) are placeholders, not real secrets.

| Flag | Description |
| - | - |
| `--email <string>` | email |
| `--mfa-secret <string>` | mfa-secret |
| `--password <string>` | password. Required. |
| `--url <string>` | url. Required. |
| `--username <string>` | username |
| `--vault-id <string>` | Vault ID (required) |
