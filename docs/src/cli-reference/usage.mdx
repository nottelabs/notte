## `notte usage`

Display usage statistics including credits, costs, and quotas.

| Flag | Description |
| - | - |
| `--period <string>` | Monthly period to get usage for (e.g., 'May 2025') |

## `notte usage logs`

List the API requests made with this workspace's credentials, newest first.

| Flag | Description |
| - | - |
| `--endpoint <string>` | Only show requests to this endpoint, e.g. /sessions/start |
| `--include-system` | Include Notte's own internal requests |
| `--only-current-token` | Only show requests made with the API key in use now |
| `--page <int>` | Page number (1-indexed) |
| `--page-size <int>` | Number of items per page |
