## `notte sessions pin [session-id]`

Pin an active session as the current one: the session commands use when `--session-id` is omitted, marked "*" in "notte sessions list".

Pass a session ID, or enough of its start to be unique. Without one, pick from a numbered list of active sessions.

```bash
notte sessions pin 3e1103a1
notte browser pin
```

## `notte sessions save-profile`

Save the running session's browser state (cookies, localStorage, sessionStorage) into a browser profile.

The session keeps running. Pass `--profile-id` to overwrite an existing profile, or `--name` to create a new one. With neither, the state is saved into the profile the session was started with.

| Flag | Description |
| - | - |
| `--name <string>` | Create a new profile with this name and save into it |
| `--profile-id <string>` | Existing profile to overwrite |
| `--session-id <string>` | Session ID (uses current session if not specified) |
