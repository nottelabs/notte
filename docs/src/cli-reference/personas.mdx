List, create, and operate on personas.

## `notte personas create`

Create a new persona

| Flag | Description |
| - | - |
| `--create-phone-number` | Whether to create a phone number for the persona (API default: false) |
| `--create-vault` | Whether to create a vault for the persona (API default: false) |
| `--name <string>` | name |

## `notte personas delete`

Delete the persona

| Flag | Description |
| - | - |
| `--persona-id <string>` | Persona ID (required) |

## `notte personas emails`

List emails for the persona

| Flag | Description |
| - | - |
| `--persona-id <string>` | Persona ID (required) |

## `notte personas list`

List all personas

| Flag | Description |
| - | - |
| `--include-deleted` | Include deleted personas |
| `--page <int>` | Page number (1-indexed) |
| `--page-size <int>` | Number of items per page |

## `notte personas show`

Show persona details

| Flag | Description |
| - | - |
| `--persona-id <string>` | Persona ID (required) |

## `notte personas sms`

List SMS messages for the persona

| Flag | Description |
| - | - |
| `--persona-id <string>` | Persona ID (required) |

| Flag | Description |
